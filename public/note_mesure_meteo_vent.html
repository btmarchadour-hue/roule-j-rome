🔍 1. Pourquoi la balise Winds Up (Spot 66) ne peut pas être injectée directement

Beaucoup de pratiquants consultent Winds Up sur leur téléphone. Benoît et moi avons étudié la faisabilité d'importer automatiquement leurs rafales dans le calcul de nos créneaux :

  • Absence d'API publique : Winds Up est un service commercial fermé sans flux de données gratuit pour les applications tierces.
  • Blocage strict par les navigateurs : Leurs serveurs envoient l'en-tête de sécurité X-Frame-Options: SAMEORIGIN. Tout navigateur moderne (Safari iPhone, Chrome) bloque catégoriquement son incrustation (iframe).
  • Fiabilité matérielle de la balise 66 : L'anémomètre physique de Lestrevet est régulièrement signalé hors service ou en panne de transmission pendant plusieurs semaines consécutives.
⚖️ 2. Comparatif des 3 Solutions pour l'École
⭐ Option 1 : Modèle AROME HD (Actuelle)
• Coût : 0 € (Open data Météo-France).
• Maille : Ultra-fine 1,3 km actualisée 4 fois par jour.
• Anticipation : Permet de calculer les créneaux à J-2 / J-1 pour prévenir les clients.
• Ergonomie : 1 bouton direct sur l'app ouvre la page Winds Up en 1 tap.
💼 Option 2 : Partenariat Winds Up Pro
• Coût : Abonnement annuel commercial B2B.
• Avantage : Mesure temps réel directe.
• Inconvénient : Dépendance totale à la réparation physique de leur capteur en cas de panne hivernale.
📡 Option 3 : Balise Club (Windbird)
• Coût : ~180-200 € à l'achat (sans abonnement, réseau basse consommation Sigfox).
• Autonomie : Fixée sur la remorque du club à Lestrevet.
• API Ouverte : Le réseau OpenWindMap fournit une vraie API REST gratuite et ouverte !
✍️ 3. Recommandation & Avis de Jérôme

💡 Décision proposée par Sheldon & Concepteur : Benoît : Nous conservons l'architecture actuelle (Option 1). Le calcul prévisionnel des créneaux repose sur le modèle officiel AROME HD Météo-France, et le bouton direct Winds Up permet le contrôle sur le terrain. Si Jérôme souhaite un jour mesurer son propre vent au centimètre près sur la remorque, l'achat d'un capteur Windbird sur le réseau ouvert sera la solution idéale.
